# Sirius

Телеграм-пульт для своего ПК: панель с кнопками прямо в чате — приколы, флуд, вебка, файлы, вирусный юнит. Пишется в двух стеках: эталон — **Python** (`main.py`, v6), боевой независимый порт — **нативный C# одним файлом** (`pult.cs`, v7), который собирается виндовым компилятором и не требует ни python, ни NuGet.

> Проект для собственных машин. Ставь только на то, чем владеешь или на что у тебя есть право.

---

## Состав репо

| файл | что это |
|---|---|
| `main.py` | эталон: python-бот (v6). Все тексты, тайминги и кулдауны — отсюда; с ним сверяется C#-версия |
| `pult.cs` | полный порт одним файлом (~3.3k строк) под .NET Framework 4: транспорт самописный (SOCKS5 + TLS1.2 + keep-alive), без сторонних пакетов |
| `pult.bat` | лаунчер C#-версии: сам собирает `pult.exe` виндовым `csc` и запускает |
| `toxik.cs` | нативный вирусный юнит (winlock/trap): собирается пультом на лету `csc`-ом прямо в рантайме |
| `.bat` | запуск python-версии (`py main.py`) |

---

## Что умеет

Панель в чате: категории → список приколов → у каждого кнопки `стоп / меню / статус`. При первом контакте — выбор хоста (`hostsel`), если пульт знает несколько машин.

**Экран и окна:** чёрный экран, выключение монитора, поворот, мерцание, инверсия, подмены обоев (свежий скрин + надписи сверху), стены окон по краям, тюрьма курсора, подмена окон местами, фейк BSOD, фейк «обновление Windows», фейк форматирования, хакер-терминал, скример, рикролл киоском, съём значков с рабочего стола, апокалипсис-микс.

**Флуды:** неубиваемые msgbox'ы, штурм cmd-окон, пьяная мышь, магнит курсора к центру, зажимы capslock и дисковода. Всё крутится, пока владелец не нажмёт `стопфлуд`.

**Звук:** сирена, мелодия писком, голос SAPI с извинениями, случайный спам системных звуков, смена тона.

**Файлы:** запуск по пути, `download & run` с прямой ссылки, сохранение присланного файла (и попытка старта), фото можно выдать как обои, отчёты об успехе/ошибке.

**Вебка:** снимки через avicap32 + клипборд (JPEG q85, до 4 кадров, фильтр по яркости); если камера не отвечает — честно печатает это в чат.

**Вирусный блок** (`toxik.exe`): деплой пары `a/b`, где winlock вечный — LL-хук глотает WIN/Alt+Tab/Alt+F4/ESC, цифры крутятся в кольцо, код владельца `0007` разблокирует; trap мыши сам отпускается через 10 минут; panic/persist/status идут через serial rescue-очередь. Persistence — Run-ключ (`SysTrayHealth`) → `vboot.vbs`. Код на экранах жертвы не светится: отгадать нельзя, только знать.

Состояние юнита: `vr_status` — что крутится, pid'ы, persistence, файловая структура vcore.

## Запуск

### C# версия

```bat
pult.bat            :: сборка + запуск. Боевой запуск — только когда python-бот остановлен (иначе хрип по 409)
pult.bat --getme    :: безопасная проверка связи с API без поллинга
```

Собрать руками, если хочется:

```
%WINDIR%\Microsoft.NET\Framework64\v4.0.30319\csc.exe /nologo /target:exe /platform:anycpu /optimize+ /codepage:65001 /out:pult.exe /r:System.dll /r:System.Core.dll /r:System.Web.Extensions.dll /r:System.Windows.Forms.dll /r:System.Drawing.dll pult.cs
```

`pult.bat` пересобирает перед каждым запуском — exe всегда свежий; собранный `pult.exe` кладётся рядом с `pult.cs`. Юнит `vcore/toxik.exe` пульт собирает сам при первом деплое.

### Python версия

```bat
pip install "python-telegram-bot[socks]" "httpx[socks]" Pillow
.bat
```

Python-версия — источник правды по поведению: нашёл расхождение — правь обе, эталоном считай `main.py`.

## Настройка

Константы в шапке того файла, который запускаешь (`main.py` / `pult.cs`):

- `BOT_TOKEN` — токен бота из @BotFather;
- `ALLOWED_IDS` — владельцы: только им отвечают кнопки и команды;
- `PROXY_URL` — `socks5://user:pass@host:port` (весь трафик идёт через прокси);
- `KB_CODE` — код разблокировки винлока (`0007`), набирается прямо на заблокированном экране машины;
- `PERSIST_NAME` — имя Run-ключа для persistence;
- `DATA_DIR` — рантайм-папка (по умолчанию `%LOCALAPPDATA%\TelegramBot`).

Подпись хоста на панели — первая строка `%LOCALAPPDATA%\TelegramBot\host.cfg` (иначе — имя машины).

## Runtime-структура

`%LOCALAPPDATA%\TelegramBot\`:

```
bot.lock               – эксклюзивный лок пульта (второй запуск не пускает)
host.cfg               – подпись хоста (первая строка)
vcore/                 – рантайм вируса
  toxik.cs             – исходник юнита (копируется из репо при изменениях)
  toxik.exe            – собранный юнит (кеш по содержимому)
  {job}_{role}.pid     – pid-файлы пары a/b
  stop_{job}.flag      – флаг корректной остановки (через rescue-очередь)
  abort.flag           – аварийная отмена
  wall.png             – подменные обои
  vboot.vbs            – persistence-лаунчер пары (Run-ключ SysTrayHealth)
```

## Поведение (инварианты обеих версий)

- `winlock` — вечный; снимается только кодом `0007` с клавиатуры самой машины.
- `trap` мыши — кап 10 минут, потом отпускает сам (если жертва досидела).
- `ESC` закрывает большинство оверлеев — там, где это задумано.
- Один трюк на хост за раз: занятому трюку отвечает `already крутится (title)` вместо второго запуска.
- `flood*`-приколы крутятся в цикле, пока владелец не даст `стопфлуд`.
- `vr_off` / `vr_panic` идут через serial rescue-очередь — юнит сам докатывается и корректно всё снимает.
- Пара `a/b` следит друг за другом: снес одну — вторая поднимет заново.

## Заметки

- `toxik.cs` правится свободно: пульт кеширует exe по содержимому, юнит перестроится при следующем деплое.
- Python-фолбэк вируса (`VIRUS_SRC` из старых версий) вырезан: юнит — только нативный `toxik.exe`.
- В C#-версии `judgment` поднимает винлок на ~1.5с раньше python: он не ждёт полного цикла проверки батареи. Это задокументированное отклонение, не баг.
- Транспорт C#-версии сам тянет SOCKS5 (user/pass), TLS 1.2 и HTTP keep-alive с собственным парсером чанков — зависимости не нужны.

## Почему private

Пульт — комбайн удалённого доступа и приколов: удобно рулить своей машиной из чата. На чужие компы это ставить незаконно и по-человечески дурно — не делай так.
